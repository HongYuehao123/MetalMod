# Stage 0 live validation — 2026-10-17

Stage 0 instrumentation and its vanilla baseline fixtures are validated. This is reference data,
not an optimization result. All worlds were disposable copies of the existing HMCL-managed
`MetalMod_Test_26.2` world `新的世界`; no normal mod installation or world upgrade occurred.

## Setup and evidence

- Apple M4 Pro, macOS 27.0.1, Java 26.0.1, Minecraft 26.2, native Metal, vanilla terrain.
- CB272K external display, reported maximum 60 Hz, actual render output **5120×2664**.
- Vsync Off / IMMEDIATE, Unlimited (260 sentinel); FG, SR and temporal upscaling Off.
- Shared textures, ordinary batching and buffer offsets On; fused draws Off.
- Dynamic lights enabled in copied settings with zero active sources; clustered mode Off.
- Fixed source world and route; daytime/weather/spawning/random-tick prep applied only to copies.
- Source route: `docs/phase7/spatial-benchmark/route.json`; surface waypoint 0, dense waypoint 13.
- Surface: RD16, repeatable 30-second yaw/short-flight motion. Dense: RD32, static camera.
- Core JAR SHA-256: `b1fed6aafbdd8213be8f5b9d4d0233a9959451961b4cee979f0b516eb0fa7228`.
- Raw captures, launch arguments, rejected attempts, completion records, source protection manifests
  and the full baseline manifest: `build/reports/stage0-20261017/live/`.
- `analyze_stage0.py` validates the complete suite, including matching source/settings/artifacts,
  actual pixels, external screen, native-only state, zero health errors, and clear census equality.

## Scope

This validates the Stage 0 baseline/diagnostic milestone for vanilla Metal, not Sodium rendering,
a matched mcopt reproduction, physical display cadence, input latency or a rendering optimization.
The baseline is session-sensitive, especially on the surface. The next stages remain proposals.
All five offline gates passed for the measured core artifact (934 native checks, 87+9 shaders,
236 render checks and standalone tests). Tooling checks cover existing analysis, fixture guards,
capture contamination, timestamp semantics and deterministic mod payload fingerprints.

The full suite analyzer and all 21 tooling checks (11 existing analyzer, 5 fixture guards,
5 Stage 0 analyzer tests) pass. Other desktop apps and thermal state were not isolated; these
measurements are fixture/session references rather than hardware-maximum claims.
